# Quickstart: Kubernetes on-premises

dfe-infra stands DFE up on a Kubernetes cluster you run. RKE2 is the reference distribution, and the charts assume no particular one.

1. Learn the layers, tiers and values cascade: [Deploying DFE with dfe-infra](../dfe-infra/deployment/index.md).
2. Prepare the cluster: [RKE2, the DFE Kubernetes distribution](../dfe-infra/deployment/rke2.md).
3. Decide where data is stored, before the first deploy: [storage](../dfe-infra/deployment/storage.md).
4. Deploy, test and tear down: [on-premises guide](../dfe-infra/deployment/on-prem.md).
5. Move to a newer stack: [upgrades](../dfe-infra/deployment/upgrades.md).
