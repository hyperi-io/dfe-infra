# Quickstart: Docker

dfe-docker runs the DFE stack under Docker Compose on one host: a laptop, a demo box or a proof of concept.

1. Get one event through the pipeline: [Taking DFE for a first look](../dfe-docker/evaluating.md).
2. Choose which components run: [profiles](../dfe-docker/profiles.md).
3. Set the deployment's configuration: [configuration](../dfe-docker/configuration.md).
4. Deploy, and move to a newer stack: [deploying](../dfe-docker/deploying.md).
5. Run it day to day: [operating](../dfe-docker/operating.md).
6. When something does not come up: [troubleshooting](../dfe-docker/troubleshooting.md).
