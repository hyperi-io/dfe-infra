REACHING THE STACK (no LoadBalancer -- port-forward)
----------------------------------------------------
The links page lists every surface in this layout:

  kubectl -n {{ .Release.Namespace }} port-forward svc/dfe-links 8080:8080     # http://localhost:8080
  kubectl -n {{ .Release.Namespace }} port-forward svc/dfe-ui 3000:3000        # DFE console  http://localhost:3000
  kubectl -n {{ .Release.Namespace }} port-forward svc/dfe-hyperdx 8081:8080   # HyperDX      http://localhost:8081
  kubectl -n {{ .Release.Namespace }} port-forward svc/dfe-engine 8000:8000    # engine API   http://localhost:8000/api/v1
  kubectl -n {{ .Release.Namespace }} port-forward svc/dfe-receiver 4317:8443  # OTLP/gRPC ingest

Send yourself data: point any OTLP exporter at http://localhost:4317
(gRPC) while the receiver forward runs, then query it in the console.

THIS IS A TRIAL PROFILE
-----------------------
Same charts and images as production, trial-shaped values: no edge TLS (the
gateway dependency is off; enabling it needs envoy-gateway, cert-manager and a
LoadBalancer -- README "Enabling the gateway"), no GitOps loop, no
autoscaling, laptop-sized requests. Graduating to a real deployment is a
values change onto the ArgoCD path, not a migration.
